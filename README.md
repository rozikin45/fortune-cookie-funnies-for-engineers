A tiny Node 22 TypeScript program that writes the funniest one-line fortune cookie message for a software engineer — a bug you thought you killed, coming back with a grudge.

## Run it

```sh
node main.ts
```

It writes exactly one line (101 characters, no trailing newline) to `/output/entry.txt`, deterministically — the same bytes on every run, with no input, no network, and no secrets.
